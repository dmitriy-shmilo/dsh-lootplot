# Community Creations #

Implements all of the crazy ideas, which Lootplot community had over the years.

## New Scenarios ##

- **Mall Ball**. Start with a lot of shops, which don't reroll on pulse, and an expensive reroll button. An idea by [DvdK](https://discord.com/channels/863625920991854602/1418249715690242210/1418249715690242210).

## New Items ##

- **Royal Slots**. Adds Royal Slot, which will not hold any item below epic rarity. Adds Royal Flask to spawn these slots. Adds Other Basilisk's Eye, which sets items' rarity to epic. An idea by [Time_Sink](https://discord.com/channels/863625920991854602/1390185052280852500/1390185052280852500).
